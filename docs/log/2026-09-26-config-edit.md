# `loom config edit`

## 決めたこと

- 設定ファイルをエディタで開くコマンドを `loom config edit` として追加する。将来の設定まわりの操作をまとめられるよう `config` サブコマンドの下に置く。
- エディタは git と同じく `VISUAL` → `EDITOR` → `vi` の順で決め、引数付きの値を扱えるよう `sh -c` 経由で起動する。
- 設定ファイルが無いときは空ファイルを作らず `loom init` を促す。ひな形なしの空ファイルから書かせるより `init` を通すほうが迷わないため。
- core は操作のたびに設定を読み直すので、書き間違いに早く気づけるよう、エディタ終了後に `config::load` で検査して結果を表示する。誤りがあってもファイルは戻さない。

## 作ったもの

- `cli::ConfigCommand::Edit` と `cmd_config_edit`。

## 検証

- 設定ファイルが無い場合のエラー、`EDITOR=true` での検査成功、エディタで不正な内容にした場合の検査エラー、エディタが非 0 で終了した場合のエラーを手で確認した。
