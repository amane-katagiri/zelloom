# 2026-09-29 `loom add --help` にタスク本文の書き方を足す

エージェントがユーザーの代わりに `loom add` でタスクを積むとき、今の会話の文脈を前提にした本文を書きがちになる。積まれたタスクは新しいセッションで実行されるので、そのままだと作業が進まない。

## 決めたこと

- **スキルではなくヘルプに書く**: 呼び出し方はヘルプで足りていて、足りないのは本文の書き方の注意だけだった。ヘルプならエージェントの種類に関係なく読まれる。
- **エージェント同士の呼び出しは想定しない**: `loom add` は結果を返さず、完了にも人間の承認が要るので、サブエージェントの代わりには使わない前提のまま。

## 作ったもの

- `src/cli.rs`: `add` サブコマンドに `after_help` を足し、タスクは文脈を持たない新しいセッションで実行されるので、目的・関係するファイル・制約・完了の条件を本文だけで分かるように書く、と伝える。

## 検証

- `loom add --help` の末尾に文が出ること。
- `cargo test` / `cargo clippy --all-targets` / `cargo fmt --check` がすべてクリーン。
