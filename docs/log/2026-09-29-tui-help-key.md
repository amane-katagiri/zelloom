# 2026-09-29 TUI のステータス行をキー一覧に戻すキーを足す

ステータス行のエラー/結果メッセージは次の操作が成功するまで残るので、その間キー一覧が見えなくなっていた。通常モードで `?` / `h` を押すとメッセージを消してキー一覧に戻せるようにした。現状の仕様は `docs/architecture/tui.md` を参照。

## 決めたこと

- **`?` と `h` の両方に割り当てる**: どちらもヘルプとして押されやすいキーで、通常モードではほかに使っていない。
- **メッセージを消すだけにする**: キー一覧はメッセージが無いときに出る既存の表示をそのまま使い、別のヘルプ画面は作らない。

## 作ったもの

- `src/tui/app.rs`: 通常モードの `?` / `h` で `last_message` を消す。

## 検証

- `src/tui/app.rs` の単体テスト: `?` / `h` でメッセージが消えること。
- `cargo test` / `cargo clippy --all-targets` / `cargo fmt --check` がすべてクリーン。
